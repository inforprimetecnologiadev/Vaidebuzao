# Vai de Buzão

<img src="branding/logo-vai-de-buzao.png" width="160" alt="Logo Vai de Buzão">

App Android (APK) gratuito para quem anda de ônibus em **Cuiabá, Várzea Grande e região**:
ponto de ônibus mais próximo, linhas que passam em cada ponto e qual linha pegar para chegar ao destino.
